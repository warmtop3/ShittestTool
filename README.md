# ShittestDeleter
Создано: @frankerface,
Канал: @shittest_tool

Программа для удаления bloatware и восстановления Windows Defender.

## Что умеет

Удаляет говно-софт:
- Yandex Browser
- MAX Messenger  
- 360 Total Security

Блокирует запуск bloatware в реальном времени и показывает уведомления в трее.

Блокирует сетевые соединения bloatware через Windows Firewall.

Восстанавливает Windows Defender после удаления 360 Total Security.

## Как пользоваться

Запусти программу от имени администратора.

Выбери программы из списка и нажми "Удалить". После удаления 360 Total Security нужно перезагрузить компьютер.

Кнопка "Заблокировать" запускает службу, которая автоматически убивает процессы bloatware при их запуске.

Кнопка "Восстановить Windows Defender" удаляет блокировки и включает защиту Windows обратно.

## Требования

- Windows 10/11
- Права администратора
- .NET Framework 4.7.2
